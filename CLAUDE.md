# FubuNotch v2: read this first

A rewrite of FubuNotch from scratch, native Rust. `crates/island-core`: the activity contract and the arbiter (pure, no UI, no I/O). `crates/island-webhook`: the local webhook. `app/`: the Slint island (`app/ui/island.slint`). Status and plan: `README.md`.

## The spec decides

- The architecture comes from `SPEC.html`. Until it is in `docs/`, `docs/SPEC-draft.md` stands in for it (written 23 Oct 2026 at the owner's request to build without waiting). When SPEC.html arrives, reconcile: SPEC.html wins, and the draft records what changed.
- Keep the split: the contract and the arbiter know nothing about the UI, so a different UI decision only replaces `app/`.
- Slint's software renderer is deliberate (RAM). Its limits, learnt the hard way: no per-corner radii, no drop shadows, and **a gradient background is not clipped by border-radius** (rounded shapes come out square): rounded things get solid colours; gradients only on paths and bars. Stacked rounded layers leave halos at the edges: one shape with its own border instead. A path's or stroke's gradient comes out flat too (its first stop), and `clip` is square even on a rounded rectangle: a fade is an image (`assets/wash.png`, stretched and `colorize`d, laid in rectangles that stay inside the rounded shape, as in the island's song wash). Anything bound to `animation-tick()` is re-evaluated every frame however it is rounded: a path that should move slower gets its clock from a `Timer` that runs only while it is on screen (`WaveBar`). Measured 6 Nov 2026 (Music page open, playing): a breathing glow (whole-island repaint per frame) plus 24 wash paths cost ~50 % of a core; now ~13 % vs ~6 % before the album colours. Don't switch renderer for looks without measuring RAM. It also misses some changes in the compact island (a new lyric in Line's capsule stayed off screen until the island changed size): `show_changes` flips the body's alpha by 1/255 to have it drawn again, only when what the capsule shows has changed.
- Check UI changes with a picture, even with the PC locked: `FUBUNOTCH_V2_SNAPSHOT=out.png` draws the island into a PNG and exits (no screen needed). Pair it with `FUBUNOTCH_V2_EXPANDED=1|compact`, `FUBUNOTCH_V2_TAB=<tab>`, `FUBUNOTCH_V2_SETTINGS=<page>` (snapshots Settings instead), `FUBUNOTCH_V2_THEME`, `FUBUNOTCH_V2_BG=<picture>` and the in-memory demo data `FUBUNOTCH_V2_DEMO_MUSIC|NOTIFS|TODO|WATER|FOCUS` (`DEMO_MUSIC=nolyrics` for a song without lyrics, `=ja` with Japanese lines; `FUBUNOTCH_V2_DEMO_VOLUME=<0..100>` a player volume for the music card's volume row; `FUBUNOTCH_V2_SNAPSHOT_SCALE=1` draws at 1x for pixel-for-pixel checks against a screenshot (1.5 by default); `DEMO_TODO=log` adds cleared tasks, `FUBUNOTCH_V2_TODO_LOG=1` opens the to-do log; `FUBUNOTCH_V2_DEMO_ART=rrggbb` the demo cover's colour, which the island takes on; `FUBUNOTCH_V2_DEMO_POS=<s>` how far into the song; `FUBUNOTCH_V2_LINE=1` starts with Line on, in snapshots and live; `FUBUNOTCH_V2_DND=1` with Do not disturb on; `FUBUNOTCH_V2_DEMO_WATCH=1` with a docked video's button and capsule mark; `FUBUNOTCH_V2_DEMO_ACCOUNTS=1` made-up NotchDeck accounts (NotchDeck counted as installed) for the Accounts tab; `FUBUNOTCH_V2_DEMO_PRAYER=HH:MM` pretends it is that time today for the Prayer tab, its pop-ups and the header clock, e.g. `11:47`, `20:30` for tomorrow's Subuh, or a pop-up's minute with `EXPANDED=compact`). A snapshot never touches Windows' notification settings or docks a video (`snapshot_mode`). Watch in island finds browser PiP windows through a WinEvent hook (`watch::hook`), no polling; Chrome hides a closed PiP instead of destroying it, so FubuNotch never hides one itself (it moves it out of sight) and "not visible" means closed. Never moves the user's mouse.
- The island is a popup tool window: `popup_style` + a subclass that refuses frame styles (winit puts WS_CAPTION back now and then, and Windows then paints a title bar over the island on a click).
- The look is Mini Island's (18 Nov 2026, the owner: "jangan sampe beda"): sizes, colours, fonts, radii and tabs come from `C:\Codingers\mini-island\island.ps1` (read-only) and pictures of it; a near solid body tinted from the left (`Fade`: a stretched strip, assets/fade.png, with quarter discs in whole-pixel corners, so no seams), the capsule's pill and lyric at its Extra large size. New parts copy island.ps1's numbers, not new ones.
- The open island is laid out like the Poni notch app (18 Nov 2026, the owner: "tiru yang kek poni punya"), in Mini Island's colours: 680 px wide, one top bar (the tab track, the time, round quick buttons on the right: a docked video, Do not disturb, notifications with a red count, the gear), the page across the full width, no footer. A normal page makes a 196 px panel, Lyrics 268 px, Notifications (two columns) and Accounts (one column per app) grow to fit (`PAGE_H`, `PAGE_TALL_H` in main.rs).
- Smoothness: the window never resizes (it is clipped to the island with a window region, `clip_window`); the island springs inside it with Slint `animate`, and pages fade/slide (`Page`). Resizing the OS window per frame is what looked choppy.

## Rules carried over from v1

- Secrets live in the OS credential store, never on disk or in git. One exception, on purpose: the webhook token is a file in `%APPDATA%\FubuNotch v2\token` so local scripts can read it; it only guards 127.0.0.1.
- No telemetry. Network calls only to services the user switched on.
- Never block Claude Code: if the app doesn't answer, a hook exits at once.
- Never overwrite `~/.claude/settings.json`: dated backup, merge, show the diff, write only after the user confirms.
- 0 % CPU while the island is hidden; no polling where Windows offers an event.
- Every change keeps `cargo test --workspace` green; check RAM and idle CPU after UI changes (README has the numbers).
