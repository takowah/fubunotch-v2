# FubuNotch v2: read this first

A rewrite of FubuNotch from scratch, native Rust. `crates/island-core`: the activity contract and the arbiter (pure, no UI, no I/O). `crates/island-webhook`: the local webhook. `app/`: the Slint island (`app/ui/island.slint`) and Settings (`app/ui/settings.slint`). Status and plan: `README.md`.

## The spec decides

- The architecture comes from `SPEC.html`. Until it is in `docs/`, `docs/SPEC-draft.md` stands in for it (written 23 Oct 2026 at the owner's request to build without waiting). When SPEC.html arrives, reconcile: SPEC.html wins, and the draft records what changed.
- Keep the split: the contract and the arbiter know nothing about the UI, so a different UI decision only replaces `app/`.
- Slint's software renderer is deliberate (RAM). Never switch renderer for looks. Its limits, learnt the hard way: no per-corner radii, no drop shadows, and **a gradient background is not clipped by border-radius** (rounded shapes come out square): rounded things get solid colours; gradients only on paths and bars. Stacked rounded layers leave halos at the edges: one shape with its own border instead. A path's or stroke's gradient comes out flat too (its first stop), and `clip` is square even on a rounded rectangle: a fade is an image (`assets/fade.png`, stretched and `colorize`d, with quarter discs in whole-pixel corners: `Fade` in island.slint). Pictures are scaled jaggedly: covers, app logos and Liquid Glass are handed to Slint at exactly the physical size drawn (`pixels.rs`), and the mascots only ever show at whole multiples of their 32 pixels (`Mascot` / `Chibi`, sized in `phx`). Anything bound to `animation-tick()` is re-evaluated every frame however it is rounded: a path that should move slower gets its clock from a `Timer` that runs only while it is on screen (`WaveBar`). Measured 6 Nov 2026 (Music page open, playing): a breathing glow (whole-island repaint per frame) plus 24 wash paths cost ~50 % of a core; now ~13 % vs ~6 % before the album colours. No new continuous animations without measuring CPU. It also misses some changes in the compact island (a new lyric in Line's capsule stayed off screen until the island changed size): `show_changes` flips the body's alpha by 1/255 to have it drawn again, only when what the capsule shows has changed.
- Check UI changes with a picture, even with the PC locked: `FUBUNOTCH_V2_SNAPSHOT=out.png` draws the island into a PNG and exits (no screen needed, no webhook, nothing written outside `APPDATA`). Snapshots read settings from `%APPDATA%\FubuNotch v2`: point `APPDATA` at a scratch folder, never the real one. Pair it with:
  - what is shown: `FUBUNOTCH_V2_EXPANDED=1|compact`, `FUBUNOTCH_V2_TAB=<tab>`, `FUBUNOTCH_V2_SETTINGS=<page>` (snapshots Settings instead; `FUBUNOTCH_V2_SETTINGS_HEIGHT=<px>` a taller window for a long page), `FUBUNOTCH_V2_SNAPSHOT_SCALE=1` (1.5 by default) for pixel-for-pixel checks against a screenshot;
  - the look for one run: `FUBUNOTCH_V2_THEME`, `FUBUNOTCH_V2_BG=<picture>`, `FUBUNOTCH_V2_LOOK=black|color|wallpaper|liquid`, `FUBUNOTCH_V2_LOOK_COLOR=rrggbb`, `FUBUNOTCH_V2_DEMO_WALLPAPER=<picture | rrggbb>`, `FUBUNOTCH_V2_NIGHT=<0..100>` (night warmth, pair with `DEMO_PRAYER=20:30`), `FUBUNOTCH_V2_CLOSED_OPACITY=<20..100>`, `FUBUNOTCH_V2_DEMO_BACKDROP=<picture>` (the "screen behind" for Liquid Glass and the snapshot's background);
  - in-memory demo data: `FUBUNOTCH_V2_DEMO_MUSIC` (`=nolyrics` a song without lyrics, `=ja` Japanese lines; `FUBUNOTCH_V2_DEMO_ART=rrggbb` the cover's colour, `FUBUNOTCH_V2_DEMO_POS=<s>` how far in, `FUBUNOTCH_V2_DEMO_VOLUME=<0..100>`; `FUBUNOTCH_V2_LINE=1` Line on, also live), `FUBUNOTCH_V2_DEMO_NOTIFS`, `FUBUNOTCH_V2_DEMO_ASK=1|question` (Allow / Deny, or a multiple-choice question), `FUBUNOTCH_V2_DEMO_WECHAT=1`, `FUBUNOTCH_V2_DEMO_MIC=1|cam|both`, `FUBUNOTCH_V2_DND=1`, `FUBUNOTCH_V2_DEMO_FOCUS=1|run` (today's rounds; `run` a round running), `FUBUNOTCH_V2_DEMO_WATER`, `FUBUNOTCH_V2_DEMO_TODO=1|log` (`FUBUNOTCH_V2_TODO_LOG=1` opens the log), `FUBUNOTCH_V2_DEMO_SHELF=1`, `FUBUNOTCH_V2_DEMO_PRAYER=HH:MM` and `FUBUNOTCH_V2_DEMO_DAY=HH:MM` (pretend it is that time for Prayer / Day Progress and the clock), `FUBUNOTCH_V2_DEMO_WEATHER=1`, `FUBUNOTCH_V2_DEMO_ACCOUNTS=1` with `FUBUNOTCH_V2_DEMO_USAGE=1` (made-up accounts and usage; without it a snapshot reads the real plans offline, never asking the network), `FUBUNOTCH_V2_DEMO_SCREENS=2` (two made-up screens for General → Screen).
  - The demo apps of NOTIFS and ASK wear their real Windows logos when installed. A snapshot never touches Windows' notification settings (`snapshot_mode`).
- Never moves the user's mouse and never sends desktop input; check behaviour with snapshots.
- The island is a popup tool window: `popup_style` + a subclass that refuses frame styles (winit puts WS_CAPTION back now and then, and Windows then paints a title bar over the island on a click).
- The look (19 Nov 2026) adapts Mini Island for Windows and the Poni notch app; FubuNotch keeps its own identity and mascots on it. In short: a near solid body tinted from the left (`Fade`), the capsule at Mini Island's "Extra large" size, the open island one top bar (the tab track, the time, the mascot while there is room, round quick buttons: Do not disturb, notifications with a red count, the gear) and the page across the full width. A normal page makes a 196 px panel, Lyrics 268 px; Notifications, Accounts, Control and To-do grow to fit. Those are the defaults of Settings → Appearance → Size (`LookSettings::sizes`, clamped; `WINDOW` is sized for the widest allowed, 760 px). Pages are cards on a quiet fill (`PageCard`): a coloured label, one big number, the page's one big button (`BigButton`), a bar; the theme's accent (`Mini.accent`) for anything "on" or "next".
- Text is Allo (Josh Puckett, SIL OFL 1.1, `assets/fonts/Allo-*.otf` + `OFL-Allo.txt`); Space Mono (OFL) stays built in; icons are Segoe Fluent Icons. The Look (Black, Color, Wallpaper color, Liquid Glass, night warmth, opacity when closed) is worked out in `island-core/src/look.rs` and `app/src/look.rs` and set on island.slint's `Mini` global: a light body flips ink to dark and `Mini.wash` (fills over the body) to black, so new parts use `Mini.wash.with-alpha(..)`, never `#ffffffNN`. The window has real per-pixel alpha (winit transparent + premultiplied softbuffer). Liquid Glass is CSS `backdrop-filter` done by hand: while it is on the island is left out of screen capture (`SetWindowDisplayAffinity` WDA_EXCLUDEFROMCAPTURE), `app/src/glass.rs` grabs the screen under it at a quarter size on a worker thread (~10 fps while shown, 4 fps after 5 unchanged frames, nothing while hidden, nothing redrawn when the grab's hash is the same) and `island-core/src/glass.rs` blurs, bends and tints it and cuts the rounded shape. Windows' own blur (ACCENT_ENABLE_BLURBEHIND) is not used: it ignores the window region. The wallpaper is read at start and on WM_SETTINGCHANGE, never polled.
- Smoothness: the window never resizes (it is clipped to the island with a window region, `clip_window`); the island springs inside it with Slint `animate`, and pages fade and rise (`Page`). Resizing the OS window per frame is what looked choppy.
- Docking browser picture-in-picture under the island ("Watch in island") was built and dropped on the owner's call (10 Nov 2026), and dropped again on 19 Nov 2026: don't bring it back unasked.

Show them at whole multiples only. ## Identity

- Product "FubuNotch v2": crates and exes `fubunotch-v2.exe` + `fubunotch-v2-hook.exe` (installed side by side; Claude Code's hooks run the hook exe next to the app), env vars `FUBUNOTCH_V2_*`, data in `%APPDATA%\FubuNotch v2` (`settings.json`, `data.json`, `fubunotch-v2.log`, the webhook token), the Start-with-Windows value "FubuNotch v2" under HKCU\...\Run, the `fubunotch-v2-hook` marker in Claude Code's settings, webhook port 47821. A settings.json from before 0.4.0 loads with its values and the defaults for what it lacks (`an_old_fubunotch_v2_file_keeps_its_values`).
- Never touch v1's identifier, data folders, pipe (`\\.\pipe\fubunotch-<sid>`) or the `fubunotch-hook` marker in `~/.claude/settings.json`: v1 runs on the same PC.

## Writes outside the app's data folder

Each one listed here, and each only on a click, except Windows' banners (the Notifications module's job since v1).

- Settings → Claude Code → Connect: Claude Code's `settings.json` (a dated backup, the diff shown, written after the user agrees).
- The Accounts tab (only once `%USERPROFILE%\.accountdeck` exists): a click on an account switches it (Claude Code / Codex: `CLAUDE_CONFIG_DIR` / `CODEX_HOME` in HKCU\Environment and `.accountdeck\state.json`, for terminals opened after; Claude Desktop: its saved login swapped, after a second click since Claude restarts). Settings → Accounts: add, rename, sign in (opens a terminal), remove (the folder is set aside in `.accountdeck\_removed`, never deleted).
- Settings → Accounts → Send setup, MCP servers, Chats: copy parts of one Claude Code account into another on Send / Copy (a backup of each file first; logins never touched).
- The Notifications module, while on: Windows' own banners turned off per app (HKCU, put back when the module is turned off or the app quits). Start with Windows: the Run value. Control: volume, brightness, outputs, radios, dark mode, only from its controls.
- The Accounts tab reads each Claude Code account's usage from api.anthropic.com with that account's token when the tab opens (at most every 5 min), and never refreshes or writes a token.

## Rules carried over from v1

- Secrets live in the OS credential store, never on disk or in git. One exception, on purpose: the webhook token is a file in `%APPDATA%\FubuNotch v2\token` so local scripts can read it; it only guards 127.0.0.1.
- No telemetry, no self-updater. Network calls only to services the user switched on: LRCLIB (Music → Synced lyrics), YouTube Music (its lyrics switch; also a browser song's cover), Open-Meteo (the Weather module, off by default), Anthropic's usage endpoint (the Accounts tab).
- Never block Claude Code: if the app doesn't answer, a hook exits at once.
- Never overwrite `~/.claude/settings.json`: dated backup, merge, show the diff, write only after the user confirms.
- 0 % CPU while the island is hidden; no polling where Windows offers an event.
- Every change keeps `cargo test --workspace` green; check RAM and idle CPU after UI changes (README has the numbers).
