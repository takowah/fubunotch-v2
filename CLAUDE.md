# Kanmuri: read this first

Kanmuri: a rewrite of FubuNotch (v1) from scratch, native Rust. `crates/island-core`: the activity contract and the arbiter (pure, no UI, no I/O). `crates/island-webhook`: the local webhook. `app/`: the Slint island (`app/ui/island.slint`). Status and plan: `README.md`.

## The spec decides

- The architecture comes from `SPEC.html`. Until it is in `docs/`, `docs/SPEC-draft.md` stands in for it (written 23 Oct 2026 at the owner's request to build without waiting). When SPEC.html arrives, reconcile: SPEC.html wins, and the draft records what changed.
- Keep the split: the contract and the arbiter know nothing about the UI, so a different UI decision only replaces `app/`.
- Slint's software renderer is deliberate (RAM). Its limits, learnt the hard way: no per-corner radii, no drop shadows, and **a gradient background is not clipped by border-radius** (rounded shapes come out square): rounded things get solid colours; gradients only on paths and bars. Stacked rounded layers leave halos at the edges: one shape with its own border instead. A path's or stroke's gradient comes out flat too (its first stop), and `clip` is square even on a rounded rectangle: a fade is an image (`assets/wash.png`, stretched and `colorize`d, laid in rectangles that stay inside the rounded shape, as in the island's song wash). Anything bound to `animation-tick()` is re-evaluated every frame however it is rounded: a path that should move slower gets its clock from a `Timer` that runs only while it is on screen (`WaveBar`). Measured 6 Nov 2026 (Music page open, playing): a breathing glow (whole-island repaint per frame) plus 24 wash paths cost ~50 % of a core; now ~13 % vs ~6 % before the album colours. Don't switch renderer for looks without measuring RAM. It also misses some changes in the compact island (a new lyric in Line's capsule stayed off screen until the island changed size): `show_changes` flips the body's alpha by 1/255 to have it drawn again, only when what the capsule shows has changed.
- Check UI changes with a picture, even with the PC locked: `KANMURI_SNAPSHOT=out.png` draws the island into a PNG and exits (no screen needed). Pair it with `KANMURI_EXPANDED=1|compact`, `KANMURI_TAB=<tab>`, `KANMURI_SETTINGS=<page>` (snapshots Settings instead), `KANMURI_THEME`, `KANMURI_BG=<picture>` and the in-memory demo data `KANMURI_DEMO_MUSIC|NOTIFS|TODO|WATER|FOCUS` (`DEMO_MUSIC=nolyrics` for a song without lyrics, `=ja` with Japanese lines; `KANMURI_DEMO_VOLUME=<0..100>` a player volume for the music card's volume row; `KANMURI_SNAPSHOT_SCALE=1` draws at 1x for pixel-for-pixel checks against a screenshot (1.5 by default); `DEMO_TODO=log` adds cleared tasks, `KANMURI_TODO_LOG=1` opens the to-do log; `KANMURI_DEMO_ART=rrggbb` the demo cover's colour, which the island takes on; `KANMURI_DEMO_POS=<s>` how far into the song; `KANMURI_LINE=1` starts with Line on, in snapshots and live; `KANMURI_DND=1` with Do not disturb on; `KANMURI_DEMO_WATCH=1` with a docked video's button and capsule mark; `KANMURI_DEMO_ASK=1` a pending Claude Code question ("Allow Bash?" from project kanmuri) on the capsule and at the top of the Notifications page; the demo apps of NOTIFS and ASK wear their real Windows logos, or a made-up tile when the app is not installed; `KANMURI_DEMO_WECHAT=1` a WeChat "New message" on the capsule and the Notifications page (an app without Windows notifications: found live by its flashing taskbar button, `flash.rs`, a shell hook), with WeChat's own exe icon when installed; `KANMURI_DEMO_MIC=1|cam|both` the capsule's orange microphone / green camera dot (live: `sensors.rs` waits on the ConsentStore registry keys, Settings → System → Mic & camera dot); `KANMURI_DEMO_MUSIC` songs can seek (a click or drag on the progress bar, `seek:<0..1>` → GSMTC TryChangePlaybackPositionAsync, only when the player allows it); `KANMURI_DEMO_ACCOUNTS=1` made-up accounts for the Accounts tab (live: `accounts.rs` reads and switches the accounts in `%USERPROFILE%\.accountdeck` itself, NotchDeck is no longer needed; a Claude Desktop chip asks for a second click because the switch restarts Claude), `KANMURI_DEMO_USAGE=1` made-up plans and usage under those accounts (a snapshot without it reads the real plans and Codex's session logs, offline: it never asks api.anthropic.com); `KANMURI_DEMO_PRAYER=HH:MM` pretends it is that time today for the Prayer tab, its pop-ups and the header clock, e.g. `11:47`, `20:30` for tomorrow's Subuh, or a pop-up's minute with `EXPANDED=compact`; `KANMURI_DEMO_DAY=HH:MM` pretends it is that time today for the Day Progress tab (its bar, the week/month/year cards, the next prayer under Coming up) and the header clock, e.g. `11:48`, `23:30` for after bedtime; the Look (Settings → Appearance) for one run: `KANMURI_LOOK=black|color|wallpaper|liquid`, `KANMURI_LOOK_COLOR=rrggbb`, `KANMURI_DEMO_WALLPAPER=<picture | rrggbb>` instead of the desktop's, `KANMURI_NIGHT=<0..100>` night warmth on at that strength (pair with `DEMO_PRAYER=20:30`), `KANMURI_CLOSED_OPACITY=<20..100>`; `KANMURI_DEMO_BACKDROP=<picture>` the "screen behind" the island for Liquid Glass (and the snapshot's background; `KANMURI_SETTINGS_HEIGHT=<px>` a taller Settings window for a long page); `KANMURI_DEMO_SCREENS=2` two made-up screens so General shows Screen and Move automatically (a snapshot sees no monitors; live, Move automatically, Mini Island's AutoMonitor plus "follow", runs on the foreground WinEvent hook and a 2 s timer only while a move is pending or a fullscreen window is remembered). Snapshots read settings from `%APPDATA%\Kanmuri`: point `APPDATA` at a scratch folder, never the real one. A snapshot never touches Windows' notification settings or docks a video (`snapshot_mode`). Watch in island finds browser PiP windows through a WinEvent hook (`watch::hook`), no polling; Chrome hides a closed PiP instead of destroying it, so Kanmuri never hides one itself (it moves it out of sight) and "not visible" means closed. Never moves the user's mouse.
- The island is a popup tool window: `popup_style` + a subclass that refuses frame styles (winit puts WS_CAPTION back now and then, and Windows then paints a title bar over the island on a click).
- The look is Mini Island's (18 Nov 2026, the owner: "jangan sampe beda"): sizes, colours, fonts, radii and tabs come from `C:\Codingers\mini-island\island.ps1` (read-only) and pictures of it; a near solid body tinted from the left (`Fade`: a stretched strip, assets/fade.png, with quarter discs in whole-pixel corners, so no seams), the capsule's pill and lyric at its Extra large size. New parts copy island.ps1's numbers, not new ones.
- The open island is laid out like the Poni notch app (18 Nov 2026, the owner: "tiru yang kek poni punya"), in Mini Island's colours: 680 px wide, one top bar (the tab track, the time, round quick buttons on the right: a docked video, Do not disturb, notifications with a red count, the gear), the page across the full width, no footer. A normal page makes a 196 px panel, Lyrics 268 px, Notifications (two columns) and Accounts (one column per app) grow to fit. Those are the defaults of Settings → Appearance → Size (`LookSettings::sizes`, clamped; `WINDOW` is sized for the widest allowed, 760 px).
- Text is Allo (Josh Puckett, SIL OFL 1.1, `assets/fonts/Allo-*.otf` + `OFL-Allo.txt`, weights 400–800 imported in island.slint and settings.slint; the software renderer draws the CFF outlines); icons stay Segoe Fluent Icons. The Look (Black, Color, Wallpaper color, Liquid Glass, night warmth, opacity when closed) is worked out in `island-core/src/look.rs` and `app/src/look.rs` and set on island.slint's `Mini` global: a light body flips ink to dark and `Mini.wash` (fills over the body) to black, so new parts use `Mini.wash.with-alpha(..)`, never `#ffffffNN`. The window has real per-pixel alpha (winit transparent + premultiplied softbuffer). Liquid Glass (Apple's, 18 Nov 2026; saved "glass"/"frosted" read as it) is CSS `backdrop-filter` done by hand: while the look is on the island is left out of screen capture (`SetWindowDisplayAffinity` WDA_EXCLUDEFROMCAPTURE, so it is missing from screenshots and recordings too), `app/src/glass.rs` grabs the screen under it plus a margin at a quarter size (GDI StretchBlt HALFTONE) on a worker thread ~10 fps while shown (4 fps after 5 unchanged frames, nothing while hidden, nothing redrawn when the grab's hash is the same), and `island-core/src/glass.rs` blurs (3 box passes), saturates, bends the backdrop outward near the edge (the lens), tints dark or light by the backdrop's brightness (`Mini.light`, with a gap so it doesn't flicker), adds the rim and sheen and cuts the rounded shape; the island shows it as an Image once the spring settles (`target-r`), `Mini.base` at `solid` standing in meanwhile. Windows' own blur (ACCENT_ENABLE_BLURBEHIND) is not used: it ignores the window region and blurred the whole window as a square. The wallpaper is read at start and on WM_SETTINGCHANGE (SPI_SETDESKWALLPAPER), never polled; the warmth moves with refresh's per-minute wake.
- Smoothness: the window never resizes (it is clipped to the island with a window region, `clip_window`); the island springs inside it with Slint `animate`, and pages fade/slide (`Page`). Resizing the OS window per frame is what looked choppy.

## Rules carried over from v1

- Secrets live in the OS credential store, never on disk or in git. One exception, on purpose: the webhook token is a file in `%APPDATA%\Kanmuri\token` so local scripts can read it; it only guards 127.0.0.1.
- No telemetry. Network calls only to services the user switched on.
- Never block Claude Code: if the app doesn't answer, a hook exits at once.
- Never overwrite `~/.claude/settings.json`: dated backup, merge, show the diff, write only after the user confirms.
- 0 % CPU while the island is hidden; no polling where Windows offers an event.
- Every change keeps `cargo test --workspace` green; check RAM and idle CPU after UI changes (README has the numbers).
